Scope: GitHub profile README (ForeverInLaw), rendered as stacked SVG slices from src/sections.ts. Mode: Experience. Audience: clients and developers equally; both doors (contact, repos) visible.

## Direction contract

THESIS: The whole profile is one phosphor character grid where glyph density is light: the avatar, the activity data and the name are all rendered from one luminance ramp. Refuses the badge-and-stats-card README and the plain neofetch block.

OWN-WORLD: Stone tones sampled from the avatar (dark: no ground, ink on GitHub's #0d1117 after the seam check, by user decision; tiers #4f4943 #8c857b #b8b1a9 #e6e5e4; light: transparent on GitHub white, tiers #c9c3bb #6f685e #5d564e #2d2824) plus one amber accent (#ffb43a dark, #8f4a0a light) reserved for data peaks only: top project, current year, this week's spike, night hours. One monospace (JetBrains Mono), ramp " .:-=+*#%@"; bars, charts, letterforms and the portrait are built from the ramp, never solid fills. Contacts are small linked chip images in the same type.

STORY: Visitor sees a face resolve out of characters, reads who Sergei is, sees the projects ranked by real commits, the year's activity as a glyph landscape, the night hours lit up, and leaves into a repo or a contact command.

FIRST VIEWPORT: Cover slice in two layouts (840 wide, 420 narrow via picture media). Wide: right 420px is a 96x96 glyph portrait from the avatar where density follows darkness (glowing negative on dark, ink positive on light), revealing row by row; left: whoami prompt, SERGEI in 2x2 glyph block letters, ForeverInLaw / co-founder of redstone.md, bio, then the Telegram command with a blinking cursor. The cover image links to Telegram; contact chips sit directly beneath it.

FORM: medium-native-ascii-live-scene-render (dealt challenger, chosen by user over assigned watch log). seed:3ded31326a5387c0
